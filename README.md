# Учёт личных расходов

**Что делает:** добавление и редактирование записей о тратах,
сохранение данных, график расходов по категориям.

**Для кого:** для себя — чтобы видеть, куда уходят деньги.

**Стек:** HTML, CSS, JavaScript, Chart.js, localStorage

**Демо:** (появится на день 6)

## Как запустить
1. `git clone https://github.com/логин/expense-tracker.git`
2. Открыть `index.html` в браузере

## Критерии готовности
- [ ] запись добавляется через форму
- [ ] данные не пропадают после перезагрузки страницы
- [ ] есть график по категориям
